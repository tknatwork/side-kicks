# scripts/

Fusion API Python scripts worth keeping after an MCP session, so the same result can be
rebuilt without re-prompting.

- One purpose per file. Start each with a comment saying what it builds and the units it
  expects (the Fusion API works in **centimetres** internally).
- Run one by hand from Fusion's **Scripts and Add-Ins** dialog (`Shift+S`).
- Nothing here should hold credentials.
